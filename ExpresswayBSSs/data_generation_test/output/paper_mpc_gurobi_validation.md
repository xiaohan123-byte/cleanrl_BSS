# 论文 MPC 的本机 Gurobi 验证结果

模型以 paper/main.tex 为准，路径流、路径调整、预约有效到达链、服务/失败/未决守恒、边界存活和未决交付变量由同一个 Gurobi MILP 联合求解；站内连续事件递推使用完整站级事件模式扩展式。RL 暂未训练，功率与终端系数仍为固定 Mock 参数。

求解环境：Gurobi 12.0.1，本机许可证 ID 2791221，6 个换电站。

| 场景 | 求解状态 | 关键结果 | 调整成本 | 预约失败成本 |
|---|---|---|---:|---:|
| 两用户共享库存、联合改路 | OPTIMAL，gap=0 | 一人走 [1]，另一人走 [0,2]；3 次预约服务，无失败 | 1.00 | 0.00 |
| 60 kW 充电后服务 | OPTIMAL | SOC 0.9 的电池在 0.175438596491 h 充满，请求等待相同时间后服务 | 0.00 | 0.00 |
| 0 kW 预约超时 | OPTIMAL | 请求在 0.25 h 超时；下游事件失活，只计一次失败 | 0.00 | 1000.00 |

三个最优解都通过了所选站级模式与统一连续事件内核的联合回放核对。详细机器可读数据见 paper_mpc_gurobi_validation.json。
