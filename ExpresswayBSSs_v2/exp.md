## 1. 实验目标与待验证假设

| 编号 | 假设 | 对应实验 |
| --- | --- | --- |
| C1 | PPO-MPC 的实际净收益与服务质量优于规则充电基线 | E1 |
| C2 | RL 充电策略相对规则充电降低成本并保障高峰供给 | E1（M0 vs M1/M2）、E5 |

| C6 | 框架在扩规模算例上保持可接受的单轮求解时间，满足实时运营要求 | E4 |

## 2. 算例设计

### 2.1 主算例（真实数据驱动，6 站基准）

以高速公路沿线真实换电网络为原型标定：

- **网络**：6 个换电站沿单向高速分布（站间距、出入口位置取自真实站址里程）；
  2–3 个 O-D 对，覆盖不同行程长度（短程 4 站、长程 6 站）。
- **价格**：分时购电价与服务费取真实站点逐时数据；各站电价曲线可不同。
- **需求**：随机用户逐站逐时到达率由真实多日需求序列统计（分时段泊松强度）；
  预约用户的 O-D、入口时刻、入口 SOC 按文档化分布生成（入口时刻集中于白天
  出行高峰、入口 SOC 取截断正态等，假设需在论文中写明）。
- **运营参数**：运营日 24 h（24 个外层区间），σ = 1 h，H = 4；
  每站 5 槽；E_B、续航、车速、充电效率、单槽功率上限按主流车型/电站标定；
  Δt = 0.25 h；SOC 分档 3 档；D_min = 100 km；出口最低 SOC = 0.10。
- **成本系数**：κ（路径调整）、c_fail（预约违约）以服务收益量纲标定，使
  违约明显不利、调整不频繁但不锁死；β = 1 为基准，尺度校准见 E5。

### 2.2 扩规模算例（10 站）

- 10 站 × 8 槽、24 h、H = 6、3–4 个 O-D 对，预约量与随机到达率按站数同比放大；
- 用途：E4 规模与计算效率，不作为主结果表的主要依据。

### 2.3 参数总表（论文 Table：算例参数）

参数表按论文符号列出：σ、H、Δt、站数/槽数、位置、E_B、续航、车速、η、
单槽功率上限 P̄、站级区间能量上限 Ē、SOC 分档、s_d、D_min、κ、c_fail、β、
价格范围、需求强度范围、初始 SOC 分布、求解器配置（Threads=1、MIPGap=0、
FeasibilityTol=1e-8、时限）。所有随机分布给出种子与生成公式，保证可复现。

### 2.4 预测误差模型

预测随机需求与真实到达分离生成：真实流由独立随机流抽样，预测流给条件均值
（可加乘性/加性噪声档位，用于 E3 预测误差灵敏度）。预约的实际入口时刻与 SOC
允许偏离预约值（偏差分布文档化），用于检验在线优化的稳健性。

## 3. 实验协议（可复现性）

落实 `todo.md` P0 的全部条目：

1. **种子管理**：训练种子、验证种子（调参/选 checkpoint）、测试种子严格分离；
   测试种子 ≥ 30 个。所有方法在同一组测试日输入上运行，配对比较，禁止各自
   重新抽样。
2. **输入固定**：候选网络、预约样本、预测需求、实际到达、电价在同一算例内
   对所有方法完全相同，仅决策策略不同。
3. **元数据快照**：每次运行保存代码版本、schema 版本、参数快照、输入文件
   哈希、求解器版本、求解状态、MIP gap、best bound、运行时间与异常信息。
4. **结果口径**：全天绩效只按真实账本（realized ledger）累计；重叠滚动窗口
   的预测目标不参与累计。终端库存处理（β 或终端约束）在所有方法间口径一致，
   或在表格中明确标注差异。
5. **确定性**：同配置同种子重跑，业务决策与汇总指标一致（求解时间等诊断
   字段除外）。

## 4. 对比方法与消融矩阵

### 4.1 方法清单

| 编号 | 方法 | 说明 | 回答的问题 |
| --- | --- | --- | --- |
| M0 | **PPO-MPC（本文）** | 训练后 actor 供逐槽请求功率，critic 供终端价值 | 主方法 |
| M1 | MPC + 低 SOC 优先充电 | 规则充电（现有 Mock 规则），其余同 M0 | C2 |
| M2 | MPC + 谷价阈值充电 | 仅低价时段满功率、高价时段保底的规则 | C2（充电智能性） |
| M3 | MPC（H=1） | 单步短视滚动，其余同 M0 | C4 |
| M4 | MPC（β=0） | 移除 critic 终端价值，其余同 M0 | C3 |
| UB | 完美信息全日 MILP | 预知全部真实预约与随机到达，一次性求解 | C5（非因果上界） |

所有方法共享：预约优先与类内 FCFS、功率/能量上限、SOC 转移、价格、实际
需求样本、账本口径。

### 4.2 消融组合

分离"滚动前瞻"与"终端价值"两个机制的独立贡献：

| | β=0 | β=1（critic） | Mock 线性终端价值 |
| --- | --- | --- | --- |
| H=1 | ✔ | ✔ | — |
| H=4 | ✔ | ✔（=M0） | ✔（≈M1 的终端项对照） |

## 5. 指标体系

五个维度，全部按测试种子汇总：均值 ± 标准差、中位数、四分位、95% 置信区间，
并报告最差种子；方法间比较用逐种子配对差值的置信区间。

1. **业务**：实际净收益及分项（预约收入、随机收入、充电成本、调整成本、
   违约成本）、预约履约率、随机服务率、路径调整次数/用户、平均等待时间。
2. **库存**：日末逐站 SOC 与满电数、站间库存不均衡度、逐时充电量与电价
   的对齐程度（谷段充电占比）。
3. **预测**：分站分时需求数量与 SOC 预测的 MAE/RMSE；预测误差与拒单、
   收益损失的相关性。
4. **计算**：单轮求解时间（均值/P95/最大）、全天墙钟、MIP gap、不可行率、
   PPO 训练收敛曲线与训练耗时。
5. **差距**：`gap = (UB − online) / |UB|`，并按 C5 分解来源。

## 6. 实验分组（详细设计）

### E1 主对比（验证 C1、C2、C5；对应论文 5.2）

**设置**

- 算例：主算例（6 站，2.1 节）；方法：M0–M4 + UB；30 个测试种子。
- M0 使用验证集选定的 checkpoint；测试种子不参与任何调参与模型选择。
- 所有方法同机、同求解器配置（Threads=1、MIPGap=0、FeasibilityTol=1e-8）。

**流程**

1. 预生成 30 个测试日输入（网络、预约、预测需求、实际到达、电价全部落盘，
   记录输入哈希）；同一测试日对所有方法逐位复用。
2. 每个（方法 × 种子）独立运行滚动仿真，保存逐轮记录与真实账本。
3. UB：用同一测试日的全部真实到达构造一次性全日 MILP；若时限内不能证明
   最优，保存 incumbent、best bound 与 MIP gap，并在表格中注明上界口径。
4. 汇总各指标，计算配对差值及其 95% 置信区间。

**输出**

- T2 主结果表：净收益（均值±std）、收入/成本分项、预约履约率、随机服务率、
  平均等待时间、路径调整次数、单轮求解时间、相对 UB 的 gap；附 M0 减各基线
  的配对差值 CI 与最差种子。
- F2 典型日轨迹（取 M0 净收益中位数的种子）：电价、充电功率、满电库存、
  服务与超时事件的日内时序，M0 与 M1 对照。
- F3 关键指标 30 种子箱线图；F5 相对 UB 的差距。

**验收标准**

- M0 净收益相对 M1/M2 的配对差值 CI 不含 0 且方向为正；预约履约率不劣于
  任何基线；结论不依赖单一种子。
- UB 在多数种子里可证明最优或 gap 可解释；`gap = (UB − M0)/|UB|` 给出量级。

### E2 消融（验证 C3、C4；对应论文 5.3）

**H 扫描（C4）**

- 变量：H ∈ {1, 2, 4, 6}；固定 β=1、其余基准；每档 ≥10 个测试种子（配对）。
- 指标：净收益、充电成本、履约率、单轮求解时间（均值/P95）。
- 输出：H–收益与 H–求解时间双轴曲线。
- 预期：收益随 H 递增但趋缓、求解时间增长 → 论证 H=4 接近收益–代价拐点。

**β 扫描（C3）**

- 变量：β ∈ {0, 0.5, 1, 2}；固定 H=4；每档 ≥10 个测试种子（配对）。
- 指标：净收益；末端效应专项指标——日末逐站满电库存、运营日最后 2 h 的
  预约违约与随机拒绝次数、日末 SOC 分布。
- 预期：β=0 时日末库存被透支、末段违约/拒绝增多；β 过大时域内收益被牺牲；
  β=1 附近取得平衡（具体取值结合 E5 的 critic 尺度校准）。

**组合消融矩阵**

- 按 4.2 节矩阵运行 {H=1, H=4} × {β=0, β=1}，并加 Mock 线性终端价值对照，
  分离滚动前瞻与终端价值两个机制的独立增益；每格 ≥10 种子。

**成本系数稳健性**

- 单因子扰动：c_fail ∈ {0.5, 1, 2} × 基准值，κ ∈ {0.1, 1, 10} × 基准值；
  报告净收益与违约/调整行为指标的变化幅度，说明结论对成本系数不敏感。

**输出与验收**

- T3 消融表：各配置的业务指标与专项指标，逐项标注相对 M0 的差值。
- 验收：消融表能独立解释滚动前瞻与终端价值各自的增益方向与量级；
  H=4、β=1 处于合理权衡点；成本系数扰动下主结论方向不变。

### E3 灵敏度（稳健性与 C5 分解；对应论文 5.4）

**公共设置**：M0 与 M1 对照；每档 ≥10 个测试种子（配对）；除被扰动因子外
全部取主算例基准值。

| 因子 | 档位 | 主要观察点 |
| --- | --- | --- |
| 需求强度 | ×{0.7, 1.0, 1.3} | 供需紧张时 M0–M1 差距是否放大（库存价值凸显） |
| 供给紧张度 | 槽位 {3, 5, 8}/站；能量限额 ×{0.75, 1.0, 1.25} | 资源受限下服务率与净收益的退化程度 |
| 电价结构 | 真实 TOU vs 平坦电价 | 平坦电价下 M0 优势应缩小 → 佐证 RL 学到谷价转移 |
| 预测误差 | 无 / 中 / 高（真实流 = 预测 × (1+ε)，ε 档位文档化） | 预测质量对收益与拒单的影响；C5 分解输入 |
| 预约占比 | {30%, 50%, 70%} | 异质用户结构对履约率与随机服务率的影响 |

**C5 差距分解（结合 E1 的 UB）**

- 三档对比：UB（完美信息、全日一次性）— oracle 需求在线（预测需求替换为
  真实需求的滚动 MPC，仍受有限时域与策略限制）— 正常在线（M0）。
- 分解：UB 与 oracle 在线之差 ≈ 有限时域 + 策略损失；oracle 在线与正常在线
  之差 ≈ 预测误差损失。两者相加应解释 UB 与 M0 的总差距。

**输出与验收**

- F4 灵敏度曲线组（每个因子一张小图：净收益/服务率 vs 档位，M0 与 M1 双线）。
- 验收：各因子下主结论方向稳定；紧张工况下框架优势不反转；总差距分解
  各部分量级可解释。

### E4 规模与计算效率（验证 C6；对应论文 5.5）

**设置**

- 算例：6 站基准（5 槽、24 区间、H=4）vs 10 站扩规模（8 槽、24 区间、H=6，
  预约量与随机到达率同比放大）；方法 M0、M1；≥10 个测试种子。

**指标**

- 模型规模：单轮 MILP 的变量数、约束数、候选事件数（随预约数/站数增长）。
- 求解：单轮求解时间均值/P95/最大、全天墙钟、MIP gap、不可行率、时限触发率
  （扩规模算例设固定时限，记录 incumbent 与 gap）。
- RL 开销：PPO 环境单步耗时分解（MPC 求解 / 事件引擎 / 其他）、总训练墙钟。

**输出与验收**

- T4 规模–效率表；求解时间随预约数（或事件数）的增长曲线。
- 实时性判据：主算例单轮 P95 求解时间 ≪ σ（如 < 60 s）；扩规模算例给出
  明确的可承受上限与退化方式（时限内次优但可行）。
- 验收：规模扩大后无可行性/不可行率异常；求解时间增长趋势可解释。

### E5 RL 训练分析（支撑 C2、C3；对应论文 5.3 或附录）

**训练协议**

- 训练种子 ≥5 个，验证种子独立（选 best checkpoint 与早停），测试种子即 E1
  的 30 个；报告超参数表：学习率与退火、clip 系数、γ、GAE λ、熵/价值系数、
  网络结构（置换不变 critic、逐槽 actor）、并行环境数、批量与总步数
  （按 `plan_rl.md` 口径）。

**收敛性**

- F1：episodic return 及业务分项（收入、充电成本、违约成本）随训练步的
  曲线，多种子均值 ± 标准差带；critic 的 explained variance 监控价值学习质量。

**actor 行为解读**

- 典型日充电功率–电价叠加图：统计谷段充电占比、高价段功率抑制程度；
- 需求高峰前满电库存轨迹：是否学到"提前预充、库存安全边际"；
- 与 M1 规则充电的同日对照，指出行为差异与对应成本差异。

**critic 价值尺度与 β 校准**

- λ^S（终端 SOC 边际价值）的量纲与量级：与电价 × E_B 比较，应同量级；
- ΔV^out(ρ) 随退回 SOC ρ 的曲线：单调性与量级检查；
- β 选取依据：终端价值项占域内目标的比例处于合理范围（不压倒域内收入与
  成本，也不被淹没），并与 E2 的 β 扫描相互印证。

**泛化**

- 训练/验证/测试种子的 episodic return 对比表，说明无显著过拟合。
