\section{问题描述与基本假设}

\subsection{问题描述}
考虑由多个 O--D 对及沿线换电站组成的高速公路网络。车辆从入口进入后沿下游方向行驶，经必要的换电站补能并从出口离开。各站配备固定数量的电池和充电设备。一次换电取走满电电池并退回带有剩余电量的电池，退回电池经过充电后继续服务其他用户。因此，换电站的选择既影响车辆的后续行程，也影响各站电池 SOC 和充电需求。

系统服务预约用户和随机用户两类需求。预约用户在出行前提供 O--D、计划进入高速公路的时间和入口 SOC，运营商据此提前规划其从入口至出口依次接受服务的换电站，形成全程换电路径。本文考虑的预约用户均具有满足道路与续航条件的完整换电路径，但实际能否按时获得服务还取决于沿线各站的满电电池供给。对于尚未进入高速公路的预约用户，运营商根据预约信息及最新预测更新计划；对于已经进入高速公路的预约用户，则根据实时位置、SOC 和预计到站时间调整后续换电安排。随机用户未提前预约，直接到站提出换电请求，运营商为其安排本站服务，不规划其全程换电路径。未来随机需求通过预测信息纳入运营决策，并在实际到站后更新为真实请求。

两类用户到站后均可在给定的最大等待时间内接受服务，等待期限从实际到站时刻开始计算。在同一站点已经到站且尚未超时的请求中，预约请求优先于随机请求，同类请求按原到站时刻先后服务。运营商在上述顺序和等待期限内选择换电时刻，并为请求匹配可用的满电电池；未立即获得服务的请求留在站内等待。已到站请求的原到站时刻、等待截止时刻和退回电池 SOC 在后续决策中保持不变，重新优化不重置等待期限。若预约请求超过等待期限仍未获得服务，则判定该次预约失败，计入一次失败成本，并取消该用户后续尚未完成的换电服务，不对后续请求重复计罚；随机请求超过等待期限后流失，不再接受服务，也不计预约失败成本。对于需要多次换电的预约用户，只有完成前一站换电并行驶至下一站后，才能接受下一次服务，因此前站等待会推迟后续到站时间。

站内仅使用满电电池完成换电，退回电池留在本站充电，其充电功率受到单台设备功率上限、站点总功率上限和电池容量的共同约束。运营商可以结合电池 SOC、未来换电需求和分时电价决定各块电池的充电时机与功率。换电服务按照满电电池与退回电池之间的电量差及服务时刻的单价计费，充电费用按照从电网购入的电量及对应时段的电价计算。由此，提前充电能够增加后续可用的满电电池，但也可能增加购电费用；推迟充电则可能使到站用户等待，甚至导致预约失败或随机用户流失。

随着车辆运行状态和站点供需信息更新，运营商滚动调整换电与充电安排。充电功率每个决策时段均可更新，预约用户的换电路径仅在规定的路径更新时刻允许调整，其余时刻保持已有安排。路径调整只针对尚未执行的后续换电安排，已完成的行驶和换电过程按实际记录保留，当前正在等待的换电请求也不因路径调整而取消。尚未进入高速公路的用户，其优化后的路径作为内部计划保留，进入高速前不向用户发布；偏离日前路径时设置调整惩罚以限制不必要的变动，但不计入实际运营费用。在途用户以最近发布的路径为基准，若新增或取消后续换电站，则发布新路径并计入一次实际路径调整费用，同一次调整涉及多个站点时仍只计一次。

在上述场景和运营规则下，本文研究预约用户换电路径与各站电池充电计划的联合动态优化问题。运营商需要根据当前车辆状态、站内电池 SOC、等待请求以及未来需求预测，联合确定预约用户后续依次访问的换电站、各换电请求的服务时刻及匹配电池，以及各站各块电池在不同时段的充电功率。在满足车辆续航、到达出口时的 SOC 要求、服务顺序、等待期限和充电能力等约束的前提下，优化目标是最大化换电网络的累计净收益，综合权衡换电服务收入、充电费用、路径调整成本和预约失败成本。换电路径决定各站需求的时空分布及退回电池状态，充电计划决定满电电池何时可用，两者共同影响当前服务和后续运营。为适应预约信息偏差、行驶时间变化及随机需求，本文在有限预测时域内反复优化，仅执行当前时段的决策，再根据新观测向前滚动；同时利用终端价值评价预测期末的电池状态和未完成服务对后续净收益的影响，使当前决策兼顾预测域之外的运营需求。

\subsection{基本假设}
为描述上述运营过程，作如下假设。
\begin{enumerate}[label=\textbf{假设\arabic*.},leftmargin=4.4em]
  \item 车辆沿高速公路下游方向行驶，并按照给定换电站序完成行程。
  \item 可交换电池具有统一容量和规格。每次换电取走和退回各一块电池，站内电池数量保持不变。
  \item 充每块电池的健康程度和充电效率一致，电池 SOC 按输入电量线性变化。
  \item 换电视为瞬时操作。
  \item 每轮可获得当前电池状态、等待请求及在途车辆的位置和 SOC。
\end{enumerate}
