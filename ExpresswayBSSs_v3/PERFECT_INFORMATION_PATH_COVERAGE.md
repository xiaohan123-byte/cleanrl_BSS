# 完美信息全天固定路径的覆盖性检查

结论：在当前道路、车辆运动、路径保护和收费规则下，可以在每位用户入场前确定一条完整路径，并联合优化全天服务与充电，不必再为未来每个路径更新时刻建立路径修改变量。其最优实际净收益不低于任何合法在线执行方案的实际净收益。

这里保留原有路径规则，不放宽最小间距剪枝。关键是使用真实入口 SOC 构造完美信息初始网络，并保护与其他实验完全相同的原始日前路径。不能只把原求解器的 H 改大，也不能丢弃原日前路径重新做无保护剪枝。

## 1. 为什么不会漏掉后来才允许的路线

`src/candidate_network.py` 的 `build_user_arcs` 先枚举物理可达的完整路径，再保护已有可行计划的全部弧。保护路径本身始终是一个完整可行的备选路径。

因此，对任何不属于保护路径的短间距弧，删除它之后至少还有保护路径可选；该短弧一定可以删除。属于保护路径的短弧则不会被删除。剪枝等价于：在物理可达路径中，禁止使用不属于当前保护计划的短间距弧。

每次新计划只能从该网络中选择，因而不能加入新的短间距弧。归纳可知，后续计划中的短间距弧始终来自最初的日前保护路径。已经执行过的短弧也符合这个条件。虚拟起点的首段用入口或最近实际换电位置计算间距，故车辆向前移动不会把一条短弧重新解释成长弧。车辆单向行驶、按距离消耗 SOC、换电后满电，保证后续可执行行程在入口真实 SOC 下也是一条完整物理可行路径。

所有合法在线实际换电序列，以及失败时仍保留的可行续行计划，都属于“真实入口 SOC＋原日前保护路径”生成的初始完美信息候选集合。固定一条选中的路径后，其剩余部分继续受到同一保护规则保护，可以合法地一直保持不变。

## 2. 从路径覆盖到收益上界

任取一个合法在线方案，取该用户实际发生的换电站顺序；若用户失败，则保留导致失败的到站请求，并用失败前最后一个可行计划补全未执行的后缀。上述序列属于初始完美信息候选集合。

完美信息方案在时间零为尚未入场的用户预先保留这些路径，并复制原方案的服务时刻、电池匹配和充电功率。车辆均沿同一条道路行驶，真实分段速度对该用户固定，改变尚未到达的目标站本身不产生额外行驶时间。复制实际换电与等待安排后，实际到站时刻、退回 SOC、等待队列及服务优先关系均保持不变；随机请求不变，电池状态和功率约束也保持不变。

初始未发布计划可以在时间零这一合法更新时刻调整，尚未入场的调整不计实际费用。随后不再更改发布路径，实际调整费用为零，其余收入及费用可保持原值。因此固定完美信息方案的实际净收益至少等于被复制在线方案的实际净收益。这个论证不要求读取任何零终端实验轨迹。

本次 7 个固定测试日的所有预约实际入口时刻均严格大于零，满足上述入场前初始化条件。该结论依赖当前的单向道路、按距离耗电、固定真实分段行驶倍率、可行计划保护及非负路径调整费用；若以后增加绕行时间、临时封路、行驶中额外 SOC 损失或入场前实际调整费用，需要重新检查。

## 3. 已执行的交叉检查

`check_perfect_information_path_coverage.py` 只读取固定输入数据、原始日前计划和相关模型源码，不读取零终端实验输出，不调用优化求解器，不重新抽样。

对固定测试日 `[1,37,3,4,19,13,14]` 的全部 1,400 名预约用户，检查：

- 原日前计划在真实入口 SOC 下可行，并完整保留于初始完美信息网络。
- 原报告 SOC 保守网络中的全部候选路线均被该完美信息网络包含。
- 对每条初始候选路径的各个前缀，枚举站点边界、站点间代表位置和在站等待起点，再按当前代码重新生成后续网络；每个允许的新后缀与已经执行的前缀拼接后，仍属于初始候选集合。
- 在两个站点边界之间，车辆已行驶距离的 SOC 消耗与到下游站点所需 SOC 相抵，首段间距锚点不变，因此无需按每个连续位置逐点抽样。此枚举是对结构证明的交叉检查，不替代第 1、2 节的归纳论证。

结果：7,050 条初始完美信息候选路径，6,607 条报告 SOC 候选路径，102,197 个代表状态，1,248,414 条后缀选择，全部通过。结构化报告保留源码和场景哈希，位于 `outputs/perfect_information_path_coverage/check.json`。

复核命令（在项目目录运行）：


## 4. 对上界实验实现的约束

- 使用冻结的 7 个输入场景和原日前路径，不重新生成用户或日前基准。
- 初始候选网络使用已知真实入口 SOC，并传入 `protected_stations=原日前路径`；不再对已知真实 SOC 扣除报告误差下界。
- 使用全部真实随机请求、真实入口时刻和真实分段行驶时间，覆盖全天及完整跨日处理；同一条路线中后续到站时刻仍由前站服务时刻决定。
- 保留 15 分钟服务/充电网格、满电交付、真实槽数、功率、等待期限、服务优先和失败判定规则。
- 优化实际全日净收益。原滚动目标中“尚未入场用户偏离日前路径”的引导性惩罚不是实际费用，不能复制到离线全日收益中。固定方案没有入场后路径调整，调整次数与实际调整成本均为零，这是合法方案的结果，而非免除一次实际发生的调整费用。
- 仍需区分全日 MILP 的可行方案收益与求解器最优上界。限时求解得到的可行收益本身不保证超过某个在线方案；服务率、等待时间等只属于具体可行方案。

本次检查尚未执行完美信息全日优化，也未修改共享模型代码或第 5.1 节结果。
